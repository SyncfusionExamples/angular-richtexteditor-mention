# Angular Rich Text Editor — Mention integration

This repository is a minimal Angular sample demonstrating how to integrate Syncfusion's Mention Component with EJ2 Angular Rich Text Editor.

## Quick start

Prerequisites:

- Node.js 20.x (recommended). Also supported: Node.js 22.x or 24.x
- npm

Install dependencies and run the app:

```bash
npm install
ng serve
```

Open http://localhost:4200/ in your browser.

## What this sample shows

- How to add the Rich Text Editor to an Angular component
- How to enable and configure `Mention` inside the editor
- Using local and remote data sources for mention suggestions
- Customizing mention templates and display fields
